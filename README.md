# دومينو الشبكة — Domino LAN

لعبة دومينو جماعية لأربعة لاعبين على أربعة هواتف Android، ضمن شبكة Wi-Fi محلية أو نقطة اتصال Hotspot، دون اشتراط اتصال بالإنترنت.

## المواصفات المعتمدة

- أربعة لاعبين حقيقيين، فريقان، كل فريق لاعبان متقابلان.
- مجموعة Double-Six تتكون من 28 حجراً.
- 7 أحجار لكل لاعب، ولا توجد كومة سحب في هذا التوزيع.
- هاتف المضيف يدير حالة المباراة ويتحقق من الحركات.
- اتصال محلي عبر WebSocket، مع اكتشاف UDP وخيار إدخال عنوان المضيف يدوياً.
- الواجهة باللغة العربية واتجاه RTL.

## حالة المشروع

هذه نسخة تأسيسية (0.1.0):

- وثائق المتطلبات والقرارات الأولية موجودة في `docs/`.
- نموذج محرك قواعد الدومينو موجود في `lib/domain/`.
- طبقة اتصال محلي أولية موجودة في `lib/network/`.
- واجهة Flutter أولية موجودة في `lib/`.
- يلزم إنشاء ملفات منصة Android بواسطة Flutter SDK ثم إجراء اختبارات فعلية على الهواتف.

لم يتم اعتماد سلوك الاتصال على جميع أنواع Hotspot بعد؛ يجب اختباره على أربعة أجهزة فعلية قبل اعتباره مكتملاً.

## المتطلبات

- Flutter SDK حديث متوافق مع Dart 3.4 أو أحدث.
- Android SDK وأدوات بناء Android.
- أربعة هواتف Android للاختبار الجماعي النهائي.

## إعداد المشروع لأول مرة

من داخل مجلد المشروع:

```bash
flutter create --platforms=android .
flutter pub get
flutter test
flutter run
```

إذا أنشأ الأمر ملفات منصة Android جديدة، راجع `docs/ANDROID_SETUP.md` قبل البناء النهائي، خصوصاً أذونات الشبكة والسماح باتصالات WebSocket المحلية.

## بناء APK تجريبي

```bash
flutter build apk --debug
```

للإصدار النهائي الموقّع، يجب إعداد مفتاح توقيع Android خاص بالمطوّر وعدم رفعه إلى GitHub.

## بنية المجلدات

```text
lib/
  domain/     أحجار الدومينو ومحرك القواعد وتوزيعها
  network/    اكتشاف المضيف واتصال WebSocket المحلي
  screens/    واجهات التطبيق
  main.dart
 docs/        المتطلبات والقرارات وخطة الاختبار
 test/        اختبارات محرك اللعبة
```

## الخصوصية والأمان

لا يتطلب التطبيق حساباً أو خادماً خارجياً. رسائل اللعب تمر داخل الشبكة المحلية. يجب ألا تُرسل أحجار اللاعبين الخاصة إلى أجهزة الخصوم؛ المضيف يحتفظ بالحالة الكاملة، ويرسل لكل لاعب العرض المسموح له فقط. هذه القاعدة جزء إلزامي من طبقة جلسة اللعب التي ستُستكمل لاحقاً.
