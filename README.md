# دومينو الشبكة — Domino LAN

لعبة دومينو جماعية لأربعة لاعبين على Android وiPhone والويب، مع وضع شبكة محلية ووضع لعب عبر الإنترنت.

## المواصفات

- أربعة لاعبين حقيقيين، فريقان: المقاعد 0 و2 للفريق الأول، والمقاعد 1 و3 للفريق الثاني.
- مجموعة Double-Six من 28 حجراً، بواقع 7 أحجار لكل لاعب.
- يبدأ الدور بحجر 6–6 وفق محرك Flutter الحالي.
- لا توجد كومة سحب؛ يمرر اللاعب فقط إذا لم يكن لديه حجر صالح.
- تُحسم الجولة عند نفاد أحجار لاعب أو بعد أربعة تمريرات متتالية.
- واجهة عربية RTL.

## تطبيق الويب (PWA)

توجد واجهة ويب قابلة للتثبيت من المتصفح على Android وiPhone بعد استضافتها عبر HTTPS. تدعم حالياً:
- إدخال عنوان خادم الإنترنت.
- إنشاء غرفة أو الانضمام باستخدام رمز من ستة أرقام.
- عرض المقاعد والاستعداد وبدء المباراة.
- عرض سلسلة الأحجار وأحجار اللاعب ودوره ونتيجة الفريقين.
- إرسال الحركات والتمرير إلى الخادم والتحقق منها مركزياً.
- حفظ رمز الاستعادة محلياً لإعادة الاتصال من الجهاز نفسه.

**مهم:** خادم الإنترنت لم يُنشر بعد. بعد نشر خدمة Render، أدخل عنوانها في حقل «عنوان الخادم» داخل التطبيق. لا يوجد رابط تشغيل عام حتى الآن.

## خادم الإنترنت

المجلد `server/` يحتوي خادم Node.js وWebSocket:
- `npm ci` لتثبيت الاعتماديات.
- `npm test` لتشغيل اختبارات الغرف ومحرك اللعب.
- `npm start` لتشغيل الخادم على المنفذ 8080.
- فحص الصحة: `/health`.
- قناة WebSocket: `/ws`.
- ملف `render.yaml` يجهز إعداد خدمة Render.

محرك الخادم يوزع الأحجار ويتحقق من الدور والحجر والطرف والتمرير، ويحتفظ بالأحجار الخاصة على الخادم ويرسل لكل لاعب يده فقط. بيانات الغرف والجولات حالياً محفوظة في ذاكرة العملية؛ إعادة تشغيل الخادم تمسح الغرف والمباريات. يلزم إضافة تخزين دائم قبل اعتبار الخدمة مناسبة للاستخدام الإنتاجي.

## اللعب المحلي (Wi-Fi / Hotspot)

تطبيق Flutter الأصلي يحتوي طبقة اتصال محلية للمضيف واللاعبين. وضع الويب لا يستطيع فتح منفذ خادم محلي من داخل المتصفح؛ لذلك لا يمكن استخدام PWA وحدها كمضيف Hotspot. يبقى التطبيق الأصلي هو مسار اللعب المحلي، ويمكن لاحقاً جعل Android مضيفاً محلياً وانضمام أجهزة iPhone عبر عميل ويب محلي إذا أضيفت هذه الوصلة.

## Android وiPhone

- Android: GitHub Actions يبني APK تجريبياً.
- iOS: GitHub Actions يبني تطبيق محاكي فقط. هذا ليس ملف IPA قابلاً للتثبيت على iPhone.
- إصدار iPhone القابل للتثبيت يتطلب توقيع Apple وإعداد التوزيع المناسب، ولا يمكن إنتاجه من بناء المحاكي وحده.

## فحوص GitHub Actions

يتضمن سير العمل:
- تنسيق وتحليل واختبارات Flutter.
- بناء APK تجريبي.
- بناء iOS للمحاكي.
- التحقق من ملفات PWA وصياغة JavaScript.
- اختبارات خادم الإنترنت ومحرك الدومينو.

نجاح البناء الآلي لا يغني عن اختبار اللعب على أربعة أجهزة فعلية.
