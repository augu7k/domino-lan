# معمارية الويب والاتصال عبر الإنترنت

## الحالة الحالية

واجهة PWA في `web/` متصلة ببروتوكول خادم WebSocket في `server/`. يستطيع المستخدم إدخال عنوان الخادم المنشور، إنشاء غرفة أو الانضمام إليها، تبديل الاستعداد، بدء الجولة، ومتابعة اللعب من الويب.

## إعداد الاتصال

- عنوان HTTP/HTTPS للخدمة: مثال `https://your-service.onrender.com`.
- عنوان WebSocket: التطبيق يحول `https` إلى `wss` ويضيف المسار `/ws`.
- بروتوكول الرسائل: JSON مع `v: 1` وحقلي `type` و`payload`.
- فحص الصحة: `GET /health`.

## رسائل العميل إلى الخادم

- `create_room`: `{ playerName }`.
- `join_room`: `{ roomCode, playerName }`.
- `reconnect`: `{ roomCode, resumeToken }`.
- `set_ready`: `{ ready }`.
- `start_game`: بدء الجولة من المضيف فقط.
- `play_tile`: `{ tile: { first, second }, side: "left" | "right" }`.
- `pass_turn`: تمرير الدور عند عدم وجود حركة قانونية.
- `request_state`: طلب لقطة الحالة واليد الخاصة.
- `leave_room` و`ping`.

## رسائل الخادم إلى العميل

- `join_accepted`: بيانات اللاعب والغرفة ورمز الاستعادة.
- `room_snapshot`: المقاعد والاستعداد والاتصال.
- `game_started`: بدء الجولة.
- `game_state`: حالة عامة للوحة والدور والنتيجة، مع `yourHand` الخاصة بالمستلم فقط.
- `error`: رمز الخطأ ورسالة عربية.

## قواعد اللعبة المنفذة على الخادم

تتطابق مع محرك Flutter:
1. توليد 28 حجراً فريداً من 0–0 إلى 6–6 وخلطها.
2. توزيع 7 أحجار لكل لاعب بالتتابع.
3. صاحب 6–6 يبدأ الجولة.
4. التحقق من أن الحركة من صاحب الدور وأن الحجر ضمن يده ويطابق الطرف المختار.
5. لا يسمح بالتمرير إذا كانت هناك حركة قانونية.
6. بعد أربع تمريرات متتالية تنتهي الجولة المحجوبة؛ يفوز الفريق الأقل نقاطاً متبقية، وعند التعادل لا تضاف نقاط.
7. إذا نفدت أحجار لاعب، يفوز فريقه وتضاف نقاط أحجار الفريق المنافس المتبقية.

## حدود حالية

- خدمة Render لم تُنشر بعد؛ يجب ربط المستودع بحساب Render ونشر Blueprint من `render.yaml`.
- بيانات الغرف والجولات في الذاكرة فقط، وتضيع عند إعادة تشغيل الخدمة أو إعادة نشرها.
- لا يوجد حالياً تسجيل دخول أو حسابات دائمة أو حماية متقدمة من إساءة الاستخدام.
- الواجهة تدعم جولة واحدة؛ إعادة الجولة/المباراة وإدارة الجولات المتعددة لم تنفذ بعد.
- PWA عميل إنترنت؛ لا يمكن للمتصفح تشغيل WebSocket server محلياً أو استضافة غرفة Hotspot. وضع LAN يبقى عبر تطبيق Flutter الأصلي.

## نشر الخدمة

1. افتح Render من المتصفح وسجل الدخول.
2. اختر إنشاء Blueprint جديد وربط مستودع `augu7k/domino-lan`.
3. وافق على إعداد الخدمتين من `render.yaml` (خادم الإنترنت وموقع الويب الثابت).
4. بعد اكتمال النشر، افتح عنوان الخدمة واختبر `/health`.
5. انسخ عنوان HTTPS إلى حقل عنوان الخادم داخل PWA. لا تضف `/ws`؛ الواجهة تضيفه تلقائياً.
